# 4 Brothers World — V2 (preview)

The big redesign, kept separate from the main game so we can always go back.
Play it from the **Play V2** button on the Flake Games home page, or at
https://thedothofyak.github.io/Dya-Akara-mbarutatu.3/four-brothers-world-v2/

- `index.html` is the main game (v1.8) with V2's changes, and loads `v2.js` (heroes, ghosts, elites, Cyitors) and `v2s2.js` (hero magic, staffs, coins, the trader, legendary chests, recipe squares), `v2s3.js` (town portals), `v2s4.js` (how each hero moves, swimming and air), `v2s5.js` (living trees, and the rock's building fix), `v2s6.js` (every hero runs in a full side view), `v2s7.js` (the Warthog King can't be fought from the cliff any more), `v2s8.js` (the bigger Ghost World and its creatures), `v2s9.js` (the fuzzy's puff jumps, and how trees are drawn), `v2s10.js` (the acorn's vine) and `v2s11.js` (how each hero mines).
- V2 saves to your account separately from the main game (`fbw2:` rows, `rw2_` in the browser), and has its own multiplayer rooms. Everyone playing together needs to be on V2.

See CHANGELOG.md for what's in it.
