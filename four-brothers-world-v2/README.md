# 4 Brothers World — V2 (preview)

The big redesign, kept separate from the main game so we can always go back.
V2 was branched from v1.5, so it doesn't have the v1.6–1.8 additions yet.

- **Play V2:** https://thedothofyak.github.io/Dya-Akara-mbarutatu.3/four-brothers-world-v2/
- **Play the main game (unchanged):** https://thedothofyak.github.io/Dya-Akara-mbarutatu.3/four-brothers-world/

V2 has its own saves and its own multiplayer rooms, so playing it never changes the main game.
The first time you open V2 it copies the heroes saved in this browser, so you can keep playing them.
Everyone in a multiplayer game needs to be on V2.
