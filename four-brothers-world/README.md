# 4 Brothers World

A 2D pixel open-world platformer by four brothers. Four worlds (Fuzzy, Acorn, Rock and Ghost), four heroes, and the Duat, where all four fight together.

## Play
Open `four-brothers-world/index.html` in a browser, or pick **🌍 4 Brothers World** on the Dya'Akara main menu. `The 4 Brothers Worlds v1.1.html` is an older version, from before the game was renamed.

## Play together
1. One player clicks **Host a game** on the title screen and reads out the room code.
2. Everyone else types the code and clicks **Join**.
3. Press Play. Everyone in the same world sees the same monsters and fights the same bosses. Press X to give what you're holding to the player next to you. Press Z to drop what you're holding (hold Shift for the whole stack).

Everyone needs the same version of the game: open the same link and refresh if the game says the versions don't match.

The host's browser keeps the shared world, so the host keeps their tab open while you play. Each player's character saves on their own device. Room codes connect players directly (peer to peer) through the free PeerJS service. A few school or work networks block that; if joining fails, try another network.

## Controls and settings
Press **Esc** for the pause menu (travel back to worlds you've visited, the home screen), **H** for the controls and **O** for Settings. In Settings you can go full screen, turn the scroll wheel round, change any key or mouse button, and save your progress to a file (or load it back on another computer).

Your hero and world save in the browser by themselves, and new versions of the game keep them.
